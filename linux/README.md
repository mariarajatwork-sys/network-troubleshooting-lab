---

## 1. Network Interfaces

### Check Network Interfaces

```bash
ip addr
```

### Check Interface Status

```bash
ip link
```

### Check IP Address in Brief

```bash
ip -br addr
```

### Check a Specific Interface

```bash
ip addr show eth0
```

### Check Interface Statistics

```bash
ip -s link
```
